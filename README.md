# Fiori guideline studio (test)

Public test repo for the guideline workflow. Content lives in `content/<slug>/`.

- **Editor:** GitHub Pages, served from `docs/`. Open it, paste a GitHub token (top right), pick a guideline.
- **Versions:** "Save version" makes one commit on `update/<slug>`. "Sent for review" opens a pull request. Approvals are pull request reviews. "Approve and ship" merges to `main`.
- **Published content:** whatever is on `main`.

No server. Jira and AEM are not connected yet.
